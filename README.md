
# Simulador de Carrito de Compras

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un simulador de carrito de compras utilizando el lenguaje de programación Python. El programa permite gestionar un catálogo de productos, agregar y eliminar artículos del carrito, calcular el subtotal, aplicar descuentos y generar un ticket de venta.

El proyecto se desarrolla mediante un trabajo colaborativo utilizando Git y GitHub, con el propósito de aplicar conocimientos de programación, control de versiones y organización de proyectos.

## Objetivo

Desarrollar un sistema funcional de carrito de compras mediante Python, utilizando estructuras de datos compuestas, funciones modulares y estructuras de control. Además, implementar un flujo de trabajo colaborativo con Git y GitHub mediante el uso de ramas, commits, Pull Requests y resolución de conflictos.

## Funciones principales

El programa cuenta con las siguientes funciones:

- `cargar_catalogo()`: Carga el catálogo de productos.
- `mostrar_catalogo(catalogo)`: Muestra los productos disponibles.
- `agregar_producto()`: Agrega productos al carrito y valida el stock.
- `eliminar_producto()`: Elimina productos del carrito.
- `calcular_subtotal()`: Calcula el subtotal de la compra.
- `aplicar_descuento()`: Aplica las reglas de descuento.
- `generar_ticket()`: Genera un registro de venta y muestra el resumen de la compra.

## Estructuras de datos utilizadas

### Diccionarios

Se utilizan para almacenar el catálogo de productos, incluyendo su identificador, nombre, precio y stock.

### Listas

Se utilizan para almacenar y recorrer los productos agregados al carrito de compras.

### Tuplas

Se utilizan para representar registros de venta y datos que no deben modificarse.
